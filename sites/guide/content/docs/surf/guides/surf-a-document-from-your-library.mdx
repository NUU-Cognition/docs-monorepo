---
title: "Surf a Document from Your Library"
---

This guide takes you from a document in your library to a finished surf in the reader. At the end you have layered summaries you can zoom.

## Prerequisites

- You have a NUU account.
- You are signed in.
- The document is already in your library.
- NUU Docs has already parsed the document.

## Open your library

Sign in with your NUU account. Open your document library. The library is NUU Docs. Surf uses that library as its list of documents. You do not upload a file inside the reader.

## Pick a parsed document

Open the document you want to read. Confirm it has a parsed version. A surf runs on one document version. If the library has a newer version, you surf that version when you want the new text.

## Run a surf

Start a surf on that version. The run is queued, then it runs, then it completes or fails. One surf is one run. You can run another surf later on the same document. Each run stays available.

Wait until the run is completed. If the run is still queued or running, the reader will only show that it is not ready yet. If the run fails, the reader cannot open layers for that run.

## Open the reader

When the surf is completed, open it in the reader. The top of the reader shows the document name and a word count. The canvas shows the top layer as one or more cards. The side panel holds the outline.

If this is your first time in the reader, a short tour walks through zoom and selection. You can run the tour again later from the reader.

If the document has more than one surf, you can switch among those runs. Shared links show the latest completed run unless you open a specific run.

## Confirm you can read

You should see summary cards, not the raw file. Zoom into one card. You should see the sections under it. Zoom out. You should see the parent card again. That is a working surf.

If the reader says no surf has been run, go back to the library and start one. If the reader says you must sign in, sign in with your NUU account and open the document again.
