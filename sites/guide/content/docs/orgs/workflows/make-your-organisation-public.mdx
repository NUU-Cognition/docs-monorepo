---
title: "Make Your Organisation Public"
---

This guide shows you how to give a team organisation a public page. At the end, anyone can find the organisation on the browse screen.

## Prerequisites

- You are signed in as an owner or an admin of a team organisation.
- The organisation already exists. See [Guide - Create an Organisation](/orgs/guides/create-an-organisation) if it does not.
- You know what you want the world to see: name, tagline, picture, and whether members are listed.

You cannot make a personal organisation public. A person is public through NUU Profiles, not through this product. See [Concept - Personal and Team Organisations](/orgs/concepts/personal-and-team-organisations).

## Fill the public fields

Open the team organisation. Open the edit view.

Set the name if you need to change it. Add a tagline. Add a location and a website if you have them. Add a description. Add founded and dissolved dates if they matter. Add extra links if you want them. Set or clear the picture.

Save those fields. Saving them does not make the organisation public. The page stays private until you turn the first switch on.

## Preview the page

Use preview if you want to see the card before you publish.

Preview uses the fields on screen. It also uses the current roster choice. Members in preview come from the real members list.

Go back to editing when you are done looking.

## Turn on the public page

Find the visibility controls. Turn on the public page.

The organisation is now visible at its public address. That address uses the stable identity. The browse screen lists the organisation. See [Concept - Identity and Slug](/orgs/concepts/identity-and-slug) and [Guide - Browse Organisations](/orgs/guides/browse-organisations).

If you turn the page off later, the organisation leaves the browse screen. Visitors no longer see the public page.

## Choose the public roster

The second switch shows or hides the member list on the public page.

Turn it on if you want the world to see who belongs. Each person shows a name, a picture, and a label if one is set.

Turn it off if you want a public organisation with a private roster. The page still shows how many members there are. It does not show who they are.

You can change this switch only while the public page is on.

## Check the result

From the organisation, open the public page. Confirm the name, the picture, and the roster choice.

If something is wrong, go back to edit. Change the fields or the switches. Save again.

## Next Steps

- Invite the rest of the team before or after you publish. See [Guide - Invite Members and Set Roles](/orgs/guides/invite-members-and-set-roles).
- Read [Concept - Public Pages](/orgs/concepts/public-pages) for why the two switches are separate.
- Keep people-facing identity in NUU Profiles. See [Guide - Keep Your Personal Organisation in Step](/orgs/workflows/keep-your-personal-organisation-in-step).
