---
title: "Browse Organisations"
---

This guide shows you how to find public organisations and how to read a public page.

## Prerequisites

- You can open NUU Organisations.
- You do not need to be a member of the organisations you browse.
- You do not need to be signed in to read public pages.

Private organisations do not appear here. Personal organisations never appear here.

## Open the browse screen

Open the browse screen. It lists every public organisation in the registry. Newer organisations appear first.

Each row shows a name, a picture, a tagline if one exists, and a member count.

If no organisation is public yet, the list is empty.

## Search by name

Use the search field if the list is long. Type part of the name. Matching is fuzzy. You do not need the exact spelling.

Search looks at the name. It does not search taglines or descriptions.

Clear the search to see the full list again.

## Open a public page

Open an organisation from the list. You land on its public page.

The public page uses the stable identity of the organisation. The display name can change later. The identity does not. See [Concept - Identity and Slug](/orgs/concepts/identity-and-slug).

The page shows the name, tagline, picture, description, location, website, dates, and extra links. See [Concept - Public Pages](/orgs/concepts/public-pages) for what those fields mean.

If the public roster is on, you also see the members. Each member shows a name, a picture, and a label if one is set. If the roster is off, you still see the member count. You do not see who the members are.

If the organisation is not public, is archived, or does not exist, the page says it is not found.

## What you do not get from browse

Browse is not a directory of every organisation in NUU. It is a directory of organisations that an admin chose to make public.

You cannot join from the public page. Joining happens through an invitation. See [Guide - Invite Members and Set Roles](/orgs/guides/invite-members-and-set-roles).

You cannot see private teams that you belong to on this screen. Those live in your own organisation list.
