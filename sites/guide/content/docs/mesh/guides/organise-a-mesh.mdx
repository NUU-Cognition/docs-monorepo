---
title: "Organise a Mesh"
---

This guide shows how you shape a mesh with titles. You create documents. You nest them. You rename them. The left rail becomes a title tree you can scan.

You do not make folders. You change titles.

## Prerequisites

- You are signed in with your NUU account.
- You can edit the mesh. Owner, admin, and editor can edit. Read-only cannot.
- You know that a title is the identity of a document. See [Concept - Titles and Hierarchy](/mesh/concepts/titles-and-hierarchy).

## Create a mesh

Open the list of meshes you can access. Create a new mesh and give it a name. Then open it.

The workspace shows an empty title tree until you add a document.

## Create a document

Create a document from the workspace. Give it a title.

A plain title is enough. Use a type in parentheses if you want the row to show a kind, such as Note, Task, or Meeting.

If the new document belongs under another document, put the parent title first. Then write a space, a dot, a space, then the child name. You can also set the parent while you create the title. The result is still one title string.

The new document appears in the tree as soon as the create batch applies.

## Nest by title

To place a document under another, make the child title start with the parent title and the dot chain.

You can drag a row onto another row. That drag is a rename of the title chain. The body stays the same. Visible children of the moved row come with it.

You can also drag a row back to the root. The child prefix is removed. The leaf name stays.

If a parent title does not exist, the child still has a full title. The tree shows it under the nearest parent that does exist.

## Rename and carry children

Rename a document when the identity should change.

Onyx shows how many nested rows will follow. Confirm the rename. The mesh rewrites inbound wikilinks in the same batch. Nested titles that sat under the old name sit under the new name.

Do not put a slash in the new title. The mesh rejects a path-like title.

Rename needs a connection. If you are offline, wait until you are online.

## Import files you already have

You can add existing markdown files and media files to a mesh. Drop them on the workspace, or pick files and folders.

Onyx lists each file and the title it will use. If a title already exists, the import skips that file unless you choose to replace it. Replace writes a new change. The old bytes stay in history.

When one document lands, it opens. When many land, they appear in the tree.

## Search the tree

If you do not remember the nest, search by title in the rail. Open the match. The tree is still the map. Search is the shortcut.
