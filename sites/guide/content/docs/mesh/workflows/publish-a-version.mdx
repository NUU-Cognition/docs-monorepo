---
title: "Publish a Version"
---

This guide shows how you freeze a mesh for readers. You publish a version. You share the stable link. You can withdraw a version later.

Publish does not replace share. Share invites people into the live mesh. Publish makes a public copy that nobody can edit. See [Concept - Published Versions](/mesh/concepts/published-versions).

## Prerequisites

- You can manage the mesh. The owner and an admin can publish.
- The live mesh holds the documents you want readers to see.
- You are online. Publish needs the service.

## Prepare the live mesh

Open the live mesh. Check the titles, the links, and the media. A publish copies what the mesh holds at that moment. Later edits do not change a copy that already exists.

If you are still editing, wait. A copy that runs while you save can start again. That keeps the copy as one real snapshot.

## Publish

Open the publish surface for the mesh. Give the copy a version number. The first number is often `v1.0.0`. If you already published a three-part number, Onyx can suggest the next patch.

You can add tags. Readers browse and search with those tags. You can add a short description of what the mesh is and who it is for.

Start the publish. Wait until the copy is ready. A large mesh takes longer. A failed copy never became a version. You can publish again, or you can remove the failed row.

## Share the link

When at least one version is ready, copy the stable link. That link always opens the latest ready version.

Send that link to readers. A reader does not need edit access. A visitor without a NUU account can still open a published version as read-only.

If you need one exact number to stay on screen, open that number and share its own address. The stable link will move when you publish again.

## Read a published version

Open the public list of meshes. Browse, or search by name, tags, or owner.

Open a published version. You get the title tree, the documents, and the media. You cannot save.

If several versions exist, switch among the ready ones. A withdrawn version is marked unpublished. It does not open.

## Update or withdraw

You can change the number, the tags, and the description of a published version after it is ready. That edit is metadata. It does not thaw the documents.

You can withdraw a version. Readers then see that it is unpublished. The live mesh is not deleted. Other published versions stay.

To give readers new content, publish again with a new number. Do not expect an old frozen copy to pick up new edits.
