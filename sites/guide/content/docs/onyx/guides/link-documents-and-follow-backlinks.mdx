---
title: "Link Documents and Follow Backlinks"
---

This guide shows how titles become a web. You will write a wikilink, follow it, and see the backlink on the other document.

## Prerequisites

- You have a mesh open with at least two documents, or you are ready to create a missing one. See [Guide - Create a Mesh and Your First Documents](/onyx/guides/create-a-mesh-and-your-first-documents).
- You can edit the mesh. A read-only role cannot create documents from missing links.
- Read [Concept - About Documents and Wikilinks](/onyx/concepts/about-documents-and-wikilinks) if titles are new to you.

## Open the source document

Open the document that should point at another title. Use the tree, or use quick open and type part of the title. Stay in edit mode.

## Insert a wikilink

Type a wikilink that names the other document by title. The editor offers matching titles as you type. Pick an existing title when you want a resolved link.

If you want a page that does not exist yet, keep the title you typed. The link lands unresolved. That is valid. The document is created only when you follow the link and confirm.

You can also give a wikilink a display label. The label is what you see. The title is still the address.

## Follow the link

Click the wikilink. The workspace opens that title in the focused pane.

If the title is missing, confirm the new document. You can still change the title in that step. You can nest it under a parent. The new document opens and the link now resolves.

Open the target in a new pane if you want to keep the source in view. See [Guide - Work with Panes and Tabs](/onyx/guides/work-with-panes-and-tabs).

## Read the backlink

Open the target document. Show the context rail if it is hidden. The rail lists documents that link here. You should see the source document.

Click the backlink to return. Rename the target if you want a clearer title. The wikilink in the source updates with the rename.

## Use embeds when the target is media

An image embed is not a wikilink to a document. It names a media file in the mesh. Paste or drop an image into the body. The file is stored and the embed appears. The context rail lists that media for the current document, or for the whole mesh.

A missing embed cannot be created from the link. The bytes must exist first.

## Next steps

- If a link is hard to find later, pin the document in the tree. See [Concept - About Documents and Wikilinks](/onyx/concepts/about-documents-and-wikilinks).
- If two people edit the same page, learn conflict choice in [Concept - Core Ideas](/onyx/concepts/core-ideas).
- When the mesh is ready for others, see [Guide - Share a Mesh with Collaborators](/onyx/workflows/share-a-mesh-with-collaborators) or [Guide - Publish a Mesh for Readers](/onyx/workflows/publish-a-mesh-for-readers).
