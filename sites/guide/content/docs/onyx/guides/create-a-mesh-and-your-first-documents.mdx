---
title: "Create a Mesh and Your First Documents"
---

This guide takes you from a signed-in home screen to a mesh with documents you can edit. At the end you have a named mesh, at least one document, and a sense of the tree.

## Prerequisites

- You have a NUU account and you are signed in.
- You have a connection. Create and import need the service.
- You know that a mesh is a named collection. See [Core Ideas](/onyx/concepts/core-ideas) if that is new.

## Open home

After you sign in, Onyx shows home. Home lists meshes you own and meshes you joined. It also holds invitations and a view of published meshes.

If you have a pending invitation, accept it here. That mesh then appears in your list. This guide assumes you create a new mesh.

## Name a mesh

Create a mesh and give it a name. The name is what everyone with access will see. You can rename it later. Rename is visible to every collaborator.

The new mesh opens as the workspace. The tree on the left starts empty.

## Create a document

Create a document from the workspace or from the command palette. The workspace proposes a starting title. Change that title before you confirm.

You can use a simple title. You can also nest the new title under a document you already have. Nested titles show as children in the tree.

The new document opens in a pane. If your default mode is edit, you can type at once. If your default mode is read, switch to edit mode.

Write a short body. Edits save as you type. Add a second document the same way.

## Import files if you already have them

You can bring markdown files and media into the mesh. Pick files, or pick a folder, or drop them on the workspace. Review the plan before you confirm.

If a file would reuse a title the mesh already has, the import skips that file unless you choose to replace it. Replace keeps the old bytes in version history.

When exactly one document lands, it opens. A larger import leaves you to open documents from the tree.

## Check the tree

The left rail now lists your titles. Pin a document if you want it at the top for everyone. Open a document from the tree. Rename a document when the title is wrong. Rename rewrites wikilinks that pointed at the old title.

Delete a document only when you mean to remove it. Links to a deleted title become broken.
