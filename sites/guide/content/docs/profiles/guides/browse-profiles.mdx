---
title: "Browse Profiles"
---

This guide shows how to find public profiles and how to open one. You do not need to sign in to browse. Sign in only if you want to claim a ghost that you find.

## Prerequisites

- None for browsing.
- If you want to claim a ghost that you find, you need a NUU account and you must not already have a public profile. See [Claim a Ghost Profile](/profiles/guides/claim-a-ghost-profile).

## Open the list

Open the browse view. You see every public profile in NUU Profiles. Each row shows a display name. It can also show a handle and years of activity. A live ghost shows a ghost mark.

This list is the same set of people that other NUU products can name. See [About Attribution](/profiles/concepts/about-attribution).

## Search

Type part of a display name or a disambiguator. The list narrows to matching public profiles.

If several people share a name, look at the disambiguator in parentheses. Open the public profile if you still need more detail.

## Open a public profile

Open a row. You see the public page for that person.

The page shows the display name, and a handle if the person has an account and a username. It can show a tagline, bio, pronouns, location, website, links, affiliations, publications, and public life dates.

A live ghost does not show a handle. It shows a ghost mark. The page explains that the profile has no account yet. If managers exist, they can appear on the page.

If the public profile is yours, you can move from this page to the editor.

## If the ghost is you

If you are looking at a ghost that names you, and you do not yet have a public profile, send a claim. You can send it from the ghost, or from the claim search. An admin reviews it. See [Claim a Ghost Profile](/profiles/guides/claim-a-ghost-profile) and [About Ghosts and Claims](/profiles/concepts/about-ghosts-and-claims).

If you already have a public profile, you cannot claim the ghost. The page still lets you read the record.
