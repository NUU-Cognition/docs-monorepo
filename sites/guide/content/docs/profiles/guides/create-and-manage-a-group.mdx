---
title: "Create and Manage a Group"
---

This guide shows how to make a personal list of public profiles and how to keep that list current. At the end you have a named group with members. Other NUU products can use that group when you share with several people at once.

## Prerequisites

- You are signed in.
- You have a public profile. If you do not, follow [Set Up Your Profile](/profiles/guides/set-up-your-profile) first.
- You understand that a group is a list, not a shared team. See [About Groups](/profiles/concepts/about-groups).

## Create a group

Open your groups. Enter a name for the new group. Create it.

The name is only a label for you. Use a name that you will recognise later, such as a family list or a review set.

You now have an empty group that belongs to your public profile.

## Add members

Open the group. Search for a public profile by display name, handle, or permanent identity. Add that profile as a member.

You can add a person with an account. You can also add a ghost. Each member is a public profile.

If the person is already in the group, the service does not add them twice.

## Remove members

Open the group. Remove the member you no longer want in the list.

The person is not deleted from NUU Profiles. Only the membership in this group goes away. Their public profile stays.

## Rename a group

Open your groups. Change the name on the group. Save the name.

The members do not change. Other products that read the group still see the same people.

## Delete a group

Open your groups. Delete the group you no longer need. Confirm the delete.

This removes the list only. Member profiles are not changed. If you need the set again, create a new group and add the members again.
