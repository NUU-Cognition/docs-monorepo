---
title: "Set Up a Project"
---

This guide shows you how to create a project and give it deliverables. At the end you have a project with one or more deliverables. Each deliverable already has a closer.

## Prerequisites

- You are signed in with your NUU account.
- You have an active workspace. Use your personal workspace, or an organisation you belong to. See [Concept - About Workspaces](/operations/concepts/about-workspaces).

## Open the workspace

Switch to the workspace that should own the work. Organisation work belongs in an organisation. Personal work belongs in the personal workspace.

Open the project list for that workspace.

## Create the project

Create a project. Give it a name. You can add a next-update date. That date is optional. It is a reminder for the project. It is not a deadline.

The new project is active. Open it.

A project has several views. Use the overview for the project itself. Use the backlog for uncommitted tasks. Use deliverables for the delivery graph. Use activity for what changed on this project.

You can attach a deadline to the project now, or later. The date lives on the deadline. See [Guide - Plan Your Week](/operations/workflows/plan-your-week).

## Add deliverables

Open the deliverables view of the project. Create a deliverable. Give it a title. You can give it a date at creation. If you do, the service creates a deadline on the closer.

The service also creates the closer subsection. The closer has the deliverable name. It holds one Delivered task. You do not create the closer yourself.

Add one deliverable for each scoped outcome. Do not put every outcome in one deliverable. The graph works better when each deliverable is one chunk.

A workspace-wide deliverables list also shows these rows across projects. You can search that list by deliverable name or by project name.

## Check what you have

Open a deliverable. You should see the closer. You should see the Delivered task inside it. The deliverable is open. It stays open until the closer is done.

You can rename the project. You can rename a deliverable. If you rename a deliverable, the closer title follows.

You can delete a project or a deliverable. Deleting a deliverable removes its subsections and its tasks. Do that only when the chunk is wrong.
