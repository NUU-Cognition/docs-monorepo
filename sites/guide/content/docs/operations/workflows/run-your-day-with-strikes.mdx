---
title: "Run Your Day with Strikes"
---

This guide shows you how to run a personal day with strikes. At the end you have a small graph of targets you can act on now.

## Prerequisites

- You are signed in with your NUU account.
- You can open your personal workspace. Strikes live there. See [Concept - About Workspaces](/operations/concepts/about-workspaces).
- You know the difference between a task and a strike. A task is shared delivery work. A strike is your own target. See [Concept - Core Ideas](/operations/concepts/core-ideas).

## Open your strikes

Switch to your personal workspace. Open Strikes.

If you open Strikes from an organisation, the product tells you that strikes are personal. It then sends you to your personal workspace.

You see three views. Actionable shows targets you can do now. Map shows the personal graph. All shows every strike, including blocked, done, and archived ones.

## Create today's targets

Create a strike. Give it a title. You can add notes.

Set a do date when you plan to do it today or on a later day. Set a due date when it must be done by a time. These dates belong to the strike. They are not organisation deadlines.

Set a priority if you need one. Strike priority is personal. It is not the same ladder as task priority.

A strike can require other strikes. A required strike blocks this one until it is done. Use that when you cannot start B until A is done.

## Keep strikes beside delivery work

A strike is not a task. Completing a shared task still happens on the task.

Use a strike when you need a personal target for the day. Copy the intent into the strike title if that helps you. Do not turn every task into a strike. Pull only what you will run today.

## Work the actionable list

Open the actionable view. These are the strikes that are not blocked and not done.

Set a strike to doing when you start it. Set it to done when you finish it.

If a strike is blocked, open the All view and inspect what it requires. Complete or drop the blocker. The strike then returns to actionable.

Use the map when you want to see the personal graph. It is a picture of your strikes and the links between them. It is not the organisation delivery map.

## Close the day

Archive a strike you no longer need. Done strikes can stay in All. They leave the actionable list.

Check notifications for tasks, plan steps, and deadlines that landed during the day. Check activity in each workspace you touched. Check the changelog if you want to know what is new in the product.

Tomorrow, create or reuse strikes from the same personal list. The organisation graph stays in projects and deliverables. Your day stays in strikes.
