NUU Docs is the resource library of NUU. You add a source. The service parses that source into clean structured content. You then read the original next to the parsed version.

A source can be a PDF file. It can also be a video URL, a public article URL, or pasted transcript text. After parse, you get a document you can open, organise, and share.

You need a NUU account to use NUU Docs. Sign in first. Then you see your library.

## Who it is for

NUU Docs is for people who keep papers, reports, talks, and articles in one place. You want the original nearby. You also want a clean reading copy.

Typical work looks like this:

- You collect PDFs and talks that you will read later.
- You want structured text you can scan, search, and share.
- You want one library for your own documents and for documents other people share with you.

If you only need a one-off file viewer, this product is more than that. NUU Docs stores the source, the parse history, and the way you group those documents.

## The problem it solves

Raw sources are hard to work with. A PDF keeps layout. A video keeps time. An article keeps the host page. None of those forms is a stable, shareable reading copy.

Without a library you also lose track of versions. A later parse can improve the text. You still need the earlier parse. You still need the original.

NUU Docs keeps those pieces together:

- The source stays on the document.
- Each parse (and each edit you save) becomes a version.
- You read both sides at once. For a PDF, the two panes can stay in step.
- Tags and collections group documents without copying them.

## Where it fits

NUU Docs is the library. It is not the full reading workspace.

NUU Surf is the product that opens a parsed document as a reader. After a document is parsed, you can send it to NUU Surf. A public link also opens in NUU Surf as a read-only view. Sharing a document with a person also gives that person access to the Surf output for that document.

Use NUU Docs when you add sources, parse them, organise them, and control who can see them. Use NUU Surf when you want to read the parsed document as a reader.

## What you can do

After you sign in, you work in two main areas: documents and collections.

In the document library you can:

- Add a source and start a parse.
- Open a document and read the source pane next to the parsed pane.
- Filter by name or tag.
- See documents you own, documents shared with you, and public documents from other signed-in NUU users.

On a document you own, you can also rename it, tag it, add it to collections, share it, reparse it, report a parse problem, or delete it.

Parse has four states you will see: unparsed, parsing, parsed, and failed. A parsed document has at least one version of parsed content.

## How to start

Read [Core Ideas](/docs/concepts/core-ideas) first. That page defines document, version, parsed content, the two panes, tag, collection, share, public link, and reparse.

Then follow [How to Upload and Parse a Document](/docs/guides/how-to-upload-and-parse-a-document). After the first parse, follow [How to Read a Document](/docs/guides/how-to-read-a-document).

If you already have documents, use [How to Organise Documents](/docs/guides/how-to-organise-documents) and [How to Share a Document](/docs/workflows/how-to-share-a-document).
