---
title: "How to Upload and Parse a Document"
---

This guide takes a source from outside NUU Docs and turns it into a document with parsed content. At the end you have a document in your library and a parse in progress or complete.

## Prerequisites

- You are signed in with your NUU account.
- You have the source you want to add: a PDF, a single video URL, a public article URL, or transcript text.

## Choose the source type

Open parse from the library. Pick the kind of source.

Use a PDF for a paper, report, or article file. Use a video URL for one video, not a playlist, channel, short, or live stream. Use an article URL for a public web article. Use transcript text when you already have the words.

Paywalled or login-gated articles may not parse well. Paste enough transcript text for the service to work with. You can add an optional title and author for a transcript. Those values go into the parsed document.

## Add a PDF

Select the PDF file. The service reads the page count.

Choose the page range to parse. Use the full range to ingest the whole file. Use a shorter range to ingest only those pages. A partial range becomes a document named with that page span.

If more than one parse method is available, pick one. Then start parse.

The service uploads the file, creates the document, and starts parse. You land on the document.

## Add a URL or transcript

Paste the video URL or the article URL. Or paste the transcript text. Then start parse.

The service creates the document and starts parse. You land on the document. The original URL stays on the document so you can reparse later without losing it.

## Watch parse

On the document, parse state moves from unparsed, to parsing, to parsed or failed.

While parsing, you see progress. You can cancel if you own the document.

When parse succeeds, the parsed pane appears next to the source pane. When parse fails, you see the error. For a PDF you can start parse again. For a video, article, or transcript, a failed run does not offer that same retry on the banner. Use reparse instead. See [Guide - How to Fix a Bad Parse](/docs/workflows/how-to-fix-a-bad-parse).

A parse can succeed with a warning. A warning is not a failure. Read the warning, then decide if you need a reparse.

## What you get

You now have a document in your library. It has a name, a source type, and a parse state. If parse succeeded, it has a first version of parsed content.

You can rename the document. You can open it from the library. You can add tags and collections next.
