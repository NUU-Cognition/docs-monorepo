---
title: "How to Organise Documents"
---

This guide shows how to label documents with tags and group them in collections. At the end you can find a document by tag or open it from a collection.

## Prerequisites

- You are signed in.
- You own the documents you want to organise. You cannot put shared or public documents from other people into your collections.

## Tag a document

Open a document you own, or stay in the library list.

Add a tag. Type an existing tag to reuse it. Type a new path to create one. Use slashes to nest a tag under another tag.

The tag appears on the document. You can remove it from that document without deleting the tag.

Repeat for other documents that should share the label.

## Filter the library by tag

In your document list, open the tag filter. Select one or more tags. The list shows documents that have at least one of those tags.

You can also search by document name. Name search and tag filter work together. Clear the filters when you want the full list.

## Create a collection

Open collections. Create a collection. Give it a name. Add a description if you want.

This collection is a playlist: a named group you fill yourself. Open the collection later to edit the name or description, or to delete the group. Deleting a playlist does not delete the documents inside it.

You can also create a collection at the moment you add a document to a group. Type a new name, then add the document.

## Add a document to a collection

From a document you own, open collections for that document. Pick an existing collection, or create one and add the document.

From the library, pick a document you own and add it to a collection the same way.

A document can sit in more than one collection. If it is already in the collection, the service tells you.

To take a document out, open collections on the document and remove it from that group. The document stays in your library.

## Tag a collection

Open the collection. Add tags to the collection itself. Those tags describe the group.

You can search collections by name, description, or tag.

## Work with a book collection

A book is a collection kind for a source that splits into chapters. After a split, the collection lists chapter documents in order, grouped as front matter, chapters, and appendix items. You can parse those chapters like other documents.

Deleting a book collection removes the book and its chapters. Do not treat a book like a playlist.

See [Concept - About Tags and Collections](/docs/concepts/about-tags-and-collections) for the difference.

## What you get

Your documents have labels you can filter. Your collections are named groups you can open. The documents themselves stay in one place.
