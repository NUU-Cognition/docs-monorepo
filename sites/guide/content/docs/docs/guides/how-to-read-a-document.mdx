---
title: "How to Read a Document"
---

This guide shows how to open a document and read the source next to the parsed content. At the end you know how to move between panes, pick a version, and continue in NUU Surf if you want a reader.

## Prerequisites

- You are signed in.
- The document exists in your library, in Shared with you, or in Public.
- For the parsed pane, parse has succeeded at least once.

## Open the document

Find the document in the library. You can search by name. You can filter by tag.

Open the document. You see the name, the parse state, and the reading area.

If you own the document, you can rename it from the title. If you are a reader, you see the title only.

## Read the source pane

Look at the left side. That is the source pane.

- A PDF shows pages. You can move through pages, zoom, rotate, open fullscreen, and download.
- A video plays from the original URL.
- An article shows the original page, or a way to open the host page.
- A transcript shows the pasted text.

If parse is still running, you may only have this pane. Wait until parse finishes for the parsed pane.

## Read the parsed pane

Look at the right side after parse succeeds. That is the parsed pane.

Read the structured content. If more than one version exists, pick the version you want. The latest version is the default.

If you own the document, you can save an edit of the parsed content as a new version. Do that only when you want a new snapshot. A shared reader cannot save an edit.

## Keep the panes in step

For a PDF with page markers, scroll one pane. The other pane moves to the matching page.

If the lock is on and the motion feels wrong, turn the lock off. Then scroll each pane on its own.

If the PDF has no page markers, the panes do not stay in step. Scroll each side yourself. See [Concept - About Source and Parsed Panes](/docs/concepts/about-source-and-parsed-panes).

## Open the document in NUU Surf

When the document is parsed, you can send it to NUU Surf. Wait until that run finishes. Then open the Surf reader.

Use NUU Docs when you need the original next to the parse. Use NUU Surf when you want the parsed document as a reader.

If someone shared the document with you, you also get access to its Surf output.

## What you get

You have read the original and the parsed copy in one view. You know which version you are looking at. You can stay in NUU Docs or continue in NUU Surf.
